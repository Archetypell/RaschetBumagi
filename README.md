# Расчёт бумаги — Android

Русскоязычное Android-приложение для расчёта количества целых листов из бумажной катушки.

## Возможности
- Масса катушки вводится вместе с втулкой.
- Масса втулки фиксирована: 5 кг.
- Масса катушки выбирается в кг или г.
- Ширина и длина листа выбираются в мм, см или м.
- Граммаж вводится в г/м².
- Показываются целые листы, чистая масса бумаги, остаток и масса одного листа.
- История последних 50 расчётов хранится на устройстве.
- Историю можно очистить.

## Формула
Чистая масса бумаги = масса катушки − 5 кг.

Количество листов:
N = floor(чистая масса бумаги в граммах / масса одного листа в граммах)

Масса одного листа = граммаж × ширина в метрах × длина в метрах.

## Сборка APK
1. Установите Android Studio.
2. Откройте папку `RaschetBumagi` как проект.
3. Дождитесь синхронизации Gradle.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется Android SDK 35 и JDK 17 или новее (требование Android Gradle Plugin 8.7.3). Минимальная версия Android — 6.0 (API 23).

## Важно
Расчёт теоретический: не учитывает обрезку, брак, влажность, технологические потери и возможную неточность фактического граммажа.
