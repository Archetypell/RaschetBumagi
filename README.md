# Расчёт бумаги

Android-приложение с разделами расчёта листов, расхода смолы и лабораторных показателей.

## Лаборатория
- Одна общая масса бумаги до пропитки.
- Две пробы: операторская и неоператорская стороны.
- Для каждой пробы вводятся масса сразу после отбора и масса после 5 минут сушки.
- Отдельно вводятся массы до и после прессования для расчёта текучести.

## Формулы лабораторного расчёта
- Осмоление = (масса после пропитки − исходная масса бумаги) / исходная масса бумаги × 100%.
- Летучие = (масса до лабораторной сушки − масса после лабораторной сушки) / масса до лабораторной сушки × 100%.
- Текучесть = (масса до прессования − масса после прессования) / масса до прессования × 100%.

Для осмоления исходная масса используется как общее значение для обеих проб; методика предполагает одинаковую площадь/массу исходной бумаги и проб.

## Расчёт смолы
Ширина листа вводится в миллиметрах, длина — в метрах. Результат выводится в килограммах.

## Сборка
Проект использует Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17 и Android SDK 35.
