# Расчёт бумаги

Android-приложение с тремя разделами:

- **Расчёт листов** — расчёт количества листов из бумажной катушки. Масса втулки 5 кг; история последних 50 расчётов хранится локально.
- **Расчёт смолы** — расчёт общего расхода смолы для партии меламиновой бумаги. Длина листа по умолчанию 3,11 м, ширина, количество листов, граммаж и осмоление вводятся вручную. Результат выводится в килограммах.
- **Лаборатория** — поля для двух проб (масса до и после сушки) и двух масс для испытания текучести.

Интерфейс оформлен в графитовой теме. Лабораторные формулы намеренно не рассчитываются: их необходимо согласовать с фактической методикой предприятия, прежде чем добавлять автоматический результат.

## Сборка

Проект использует Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17 и Android SDK 35.

```bash
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
